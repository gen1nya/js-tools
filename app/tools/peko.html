Словарь языка ПЕКО

Язык ПЕКО состоит из четырех основных слов:

п = 0
пе = 1
пек = 2
пеко = 3

Как работает кодирование?

Каждый символ исходного текста преобразуется в четверичную систему счисления и записывается словами ПЕКО. Между словами можно использовать разделители: [], !?;,.@

Пример:
"А" (код 65) → п[пеко]п!п → "А" в четверичной системе с разделителями
"Привет" → "пе,пеко[пек]п!пе.пеко..."
